#  Sales Data Analysis Using Microsoft Excel

## Project Overview
This project focuses on analysing  sales data using Microsoft Excel. It explores sales performance, profitability, customer behaviour, product performance and business trends.

## Project Objective
To analyse  sales data and identify useful insights that can help understand overall business performance.

## Dataset Details
- **Dataset:** Sales Dataset
- **Total Records:** 15,000
- **Total Columns:** 21
- **Data Period:** 2024–2025

## Tools Used
- Microsoft Excel
- Excel Formulas
- PivotTables
- PivotCharts
- Slicers

## Project Work
- Data cleaning and data validation
- Calculation of key performance metrics
- Sales analysis by year, month, region and category
- Profit and product performance analysis
- Customer and return analysis
- Interactive dashboard creation
- Business insights and observations

## Dashboard
The interactive dashboard presents key sales metrics and visualisations. Slicers allow users to filter the analysis.

## Key Learnings
- Data cleaning and validation
- Using Excel formulas for calculations
- Creating PivotTables and PivotCharts
- Building interactive dashboards
- Analysing data and identifying business insights
